# devbotv1

DevBot v1 — developer assistant bot for coding workflows.

## Stack

Turborepo, TypeScript

## Getting started

```bash
git clone https://github.com/ANSHSINGH050404/devbotv1.git
cd devbotv1
bun install
bun run dev   # or: bun run start
```
